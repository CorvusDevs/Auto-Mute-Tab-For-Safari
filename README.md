Tired of background tabs blasting audio? Auto Mute Tab automatically silences inactive Safari tabs and restores sound when you switch back. Simple, fast, and lightweight.

## Features

- **Smart Auto-Muting** — Background tabs are instantly muted the moment you switch away, and audio restores seamlessly when you return
- **Picture-in-Picture Support** — Videos in PiP mode continue playing audio in the background
- **Keyboard Shortcut** — Toggle muting with Ctrl+Shift+M (customizable)
- **Domain Whitelist** — Keep specific sites unmuted at all times (music players, video calls, etc.)
- **Cross-Window Muting** — Works across all Safari windows automatically
- **Deep Media Support** — Handles HTML5 video/audio, Web Audio API, autoplay, iframes, and dynamic content
- **Lightweight** — Near-zero resource usage with no impact on browsing speed

## Privacy

No data collection, no analytics, no tracking, no network requests. Everything runs locally in Safari with complete privacy.
